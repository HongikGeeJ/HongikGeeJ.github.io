# Gemini AI (help FAB)

แท็บ **AI ช่วยเหลือ** ใน `#help-fab` เรียก Gemini ผ่าน Apps Script proxy เท่านั้น  
ดูขั้นตอนตั้งค่าเต็มที่: [`apps-script/gemini-proxy/README.md`](../../apps-script/gemini-proxy/README.md)

ใส่ `proxyUrl` ได้ที่:
- ไฟล์นี้: `gemini-config.json` → `"proxyUrl"` หลัง deploy
- หรือ HTML: `DEFAULT_GEMINI_PROXY_URL` ที่หัวสคริปต์

ไม่ใส่ API key ในไฟล์เหล่านี้
